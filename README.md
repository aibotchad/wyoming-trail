# Wyoming Trail

A text-and-sprite travel RPG in the style of The Oregon Trail, set in modern day — lead a four-person party in a pickup truck from Cheyenne, choose your own roads across Wyoming, and reach Yellowstone. Rust → WebAssembly, built with Trunk, runs in the browser.
